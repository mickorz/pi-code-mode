# Windows 平台验证报告（M2 阶段，无 Mac 环境下的当前平台验收）

> 日期：2026-11-25
> 平台：Windows（win32 x64，Node v24.18.0）
> 脚本：`dev-examples/sandbox-agent-probe/windows-check.ts`
> 结论：**Windows 拒绝路径 8/8 全部通过，零宿主机执行**

## 1. 验收目标（Windows 与 macOS/Linux 不同）

macOS/Linux 的验收目标是"沙盒真的限制了文件/网络权限"；Windows 的验收目标不同：

> 证明**每一条路径都明确拒绝，且绝不降级为宿主机执行**。

本项目 Windows 策略（用户既定决策，见执行计划 D6）：`isolation_unavailable`，不降级。

## 2. 验证结果（8/8 通过）

| 项 | 验证内容 | 结果 |
|---|---|---|
| W1 | 工厂在 win32 返回 `UnavailableCommandExecutor` | PASS |
| W2 | 工厂输出 `isolation_unavailable`，`exitCode=null`，`stdout=""` | PASS |
| W3 | `SrtCommandExecutor(win32)` 短路拒绝，**0ms**（证明未 spawn 任何进程） | PASS |
| W4 | Host 进程协议真实 spawn：fd3 收到 `failed 125`、退出码 125、marker 文件未创建、stdout 空 | PASS |
| W5 | 配置基线仍正确生成：唯一写边界 / 9 条凭据禁读 / 域名 0 条 / 10 条环境变量黑名单 | PASS |
| W6 | Adapter 链路 fail-closed：Policy 放行 → 执行层拒绝 → **磁盘零副作用** | PASS |
| W6b | 危险命令 `rm -rf /`：第一阶段 block + 第二层 Permit 拒绝（双层均生效） | PASS |
| W7 | 平台判定不依赖 SRT：`win32=false, darwin=true, linux=true` | PASS |

关键安全不变量已实证：**任何路径都不产生宿主机执行痕迹**（W2/W3/W4/W6 均断言 stdout 为空且磁盘无产物）。

## 3. SRT Windows Alpha 后端的事实（信息项，不构成承诺）

`@anthropic-ai/sandbox-runtime@0.0.81` **确实带有 Windows 后端**，实测探测结果：

- `isSupportedPlatform()` 对 `windows` 返回 **true**（这就是我们不能依赖它做平台判定的原因）。
- 所需二进制已随包存在：`node_modules/@anthropic-ai/sandbox-runtime/vendor/srt-win/x64/srt-win.exe`。
- 直接调用会报：`no srt-win path configured; set windows.srtWin.path`。
- 官方安装方式需要**一次性 UAC 提权**：

```text
npx sandbox-runtime windows-install --sublayer-guid <GUID>
# 或 installWindowsSandbox()
```

它会：创建专用 Windows 用户 `srt-sandbox`、安装 WFP 网络过滤器（按该用户 SID 绑定，不影响本机网络）、安装 MITM CA。官方称无需重启/注销。

### 采纳 Windows 后端的影响评估（如将来决定启用）

| 维度 | 影响 |
|---|---|
| 系统改动 | 需要管理员权限一次性安装；创建本地用户账号 + 网络过滤器 + 证书 |
| 隔离强度 | 上游标注 Alpha / Beta Research Preview，未经本仓库实测 |
| 平台承诺 | 与执行计划 D6「Windows explicit unsupported」冲突，需显式改决策 |
| 回滚 | `uninstallWindowsSandbox()` 可用，但已产生系统副作用 |

**当前决策不变：Windows 不支持，拒绝优先。** 是否评估该后端由用户决定，不在本次交付范围内。
