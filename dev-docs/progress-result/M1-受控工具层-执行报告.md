## 3. 安全语义（M1 实际生效的防线）

1. **第一阶段（policy-extension）**：未知工具 deny；危险命令 deny（14 规则：rm 根删除/fork 炸弹/文件系统破坏/dd 设备/提权/电源/管道执行 shell/反弹 shell/chmod 根/设备重定向/shell rc 覆盖/凭据篡改/git 钩子注入/环境注入）；受保护路径 deny；ask fail-closed（headless 无审批 UI）。
2. **第二阶段（agent-tools）**：无有效 Permit 拒绝执行——覆盖 SDK 静默放行错误形态（M0.1 C2 实证路径）、参数中途篡改（digest 不匹配）、Permit 过期/重复消费。
3. **执行层**：文件工具 canonicalize 后工作区边界强制（symlink 逃逸防护）；命令工具 M1 一律 blocked（UnavailableCommandExecutor），无任何宿主机执行旁路。
4. **runId/executionId**：CommandExecutor 请求携带执行身份（审计关联基础）。
